# Item & Purchase Management System

A simple web-based Item & Purchase Management System built using:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

The application manages item types, items, purchases, stock availability, and purchase history.

---

## 1. Project Overview

The Item & Purchase Management System provides the following functionality:

- Manage Item Types
- Manage Items
- Activate or deactivate items
- Maintain available stock
- Create purchases containing multiple items
- Validate stock before creating purchases
- Automatically deduct stock after purchase
- Update existing purchases
- Maintain purchase history
- Prevent deletion of purchases
- Prevent deletion of items that have purchase history
- Display purchase details
- Use MySQL JOINs for related data
- Use database transactions for purchase operations
- Perform backend validation
